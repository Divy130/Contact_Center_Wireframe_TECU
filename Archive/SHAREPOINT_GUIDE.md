# TECU Dashboard - SharePoint & Browser Compatibility Guide

## ⚠️ SharePoint View Issue

If you're viewing this dashboard in SharePoint and see an error message about scripts not running, **this is normal**. SharePoint has security restrictions that block external JavaScript libraries.

## ✅ How to View the Dashboard Properly

### **Option 1: Download & Open Locally (RECOMMENDED)**
This is the best way to see the full interactive dashboard with all charts:

1. **Go to GitHub Repository:**
   - https://github.com/Divy130/Contact_Center_Wireframe_TECU

2. **Download the File:**
   - Click the green "Code" button
   - Select "Download ZIP"
   - Extract the ZIP file
   - Open `TECU_Dashboard_Final.html` directly in your browser

3. **You'll see:**
   ✅ All tabs working (Overview, Performance, Real-time, Quality, Sentiment)
   ✅ Interactive filters on each section
   ✅ Live charts and visualizations
   ✅ Complete metrics definitions
   ✅ Data tables with sorting

### **Option 2: View in Browser (Without SharePoint)**
Simply open the HTML file in any modern web browser:
- Chrome
- Firefox
- Safari
- Edge

Double-click the `TECU_Dashboard_Final.html` file → Opens in your default browser → Full functionality!

### **Option 3: Online Viewing (If Hosted on GitHub Pages)**
Once GitHub Pages is enabled:
- Visit: `https://divy130.github.io/Contact_Center_Wireframe_TECU/TECU_Dashboard_Final.html`
- Full interactive experience
- No download needed
- Share the link with anyone

## 🔧 What's Different in SharePoint View?

When viewing in SharePoint:
- ✅ All text, cards, and metrics display correctly
- ✅ Tabs and filters work normally
- ✅ Tables show all data
- ⚠️ Charts show a message instead (due to security restrictions)
- ⚠️ Some styling effects may be limited

**Why?** SharePoint blocks external script libraries (Chart.js) for security reasons.
