# TECU Call Center Analytics Dashboard

A comprehensive, interactive analytics dashboard for TECU Credit Union's contact center operations.

## 📊 Features

- **5 Interactive Tabs:**
  - 📊 Overview - Quick insights, metrics definitions, and navigation
  - 📈 Performance - Historical trends, SLA analysis, volume patterns
  - 📡 Real-time - Live operations, queue status, capacity forecasting
  - ✅ Quality - QA scores, compliance metrics, performance by queue
  - 😊 Sentiment - Member feedback, sentiment trends, satisfaction drivers

- **Section-Specific Filters:**
  - Date range selection (7/30/60/90 days)
  - Channel filtering (Voice, Chat, Email)
  - Queue and team selection
  - Refresh interval controls

- **Key Metrics:**
  - SLA Compliance
  - Average Handling Time (AHT)
  - First Contact Resolution (FCR)
  - Customer Satisfaction (CSAT)
  - Agent Utilization
  - Quality Assurance Scores

- **Rich Visualizations:**
  - Line charts for trends
  - Doughnut charts for distribution
  - Stacked bar charts for volume analysis
  - Bubble charts for channel load
  - Area charts for queue depth
  - Data tables with detailed breakdowns

## 🚀 How to Use

1. **Open in Browser:**
   - Simply open `TECU_Dashboard_Final.html` in any web browser (Chrome, Firefox, Safari, Edge)
   - No installation or server required

2. **Navigate Tabs:**
   - Click tab buttons at the top to switch between sections
   - Each section has its own filters and visualizations

3. **Apply Filters:**
   - Use dropdown filters at the top of each section
   - Filters update the displayed data and charts

4. **View Metrics:**
   - Check key metrics definitions in the Overview tab
   - Hover over cards for additional details

## 📋 Key Metrics Definitions

### SLA Compliance
**Service Level Agreement** - A commitment to answer customer interactions within a specified timeframe.
- Percentage of interactions answered within the defined SLA time
- Formula: (Interactions answered within SLA / Total interactions) × 100

### Average Handling Time (AHT)
Average time agents spend handling a single customer interaction.
- Formula: Total handling time / Number of interactions

### First Contact Resolution (FCR)
Percentage of issues resolved on the first interaction without follow-up.
- Formula: (Issues resolved on first contact / Total interactions) × 100

### CSAT Score
Customer Satisfaction Score - measures member satisfaction on a 10-point scale.
- Calculated from post-call survey ratings

### Agent Utilization
Percentage of time agents spend handling interactions vs. total available time.
- Formula: (Talk time / Available time) × 100

### Quality Assurance (QA) Score
Overall compliance score based on call quality audits.
- Criteria: Greeting, verification, tone, resolution, documentation
